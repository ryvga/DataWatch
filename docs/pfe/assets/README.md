# Assets du rapport PFE

`isga-logo.png` contient le logo ISGA utilisé sur la couverture.

`oyster-logo-black.svg` et `oyster-logo-black.png` proviennent du kit média officiel d’Oyster.

Source officielle consultée en septembre 2026.

https://www.oysterhr.com/media-kit

Le PNG est dérivé du SVG officiel pour garantir un rendu stable dans Word et LibreOffice. Ces fichiers servent uniquement à identifier l’entreprise dans le rapport académique.
